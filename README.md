# 🎬 CinemaSearch

CinemaSearch is a modern movie search web application built using React. It allows users to search for movies, view detailed information, and save their favourite movies with persistent storage.

---

## 🚀 Features

- 🔍 Search movies using OMDb API
- 🎬 View detailed movie information (poster, year, plot)
- ❤️ Add and remove favourites
- ⚡ Fast and responsive UI
- 🎨 Styled with Tailwind CSS
- ✨ Smooth animations with Framer Motion

---

## 🧠 Concepts Used

- React Hooks (`useState`, `useEffect`, `useContext`, `useCallback`)
- Custom Hooks (useMovies)
- React Router (`useParams`, dynamic routing)
- Context API for global state management
- API handling & async/await
- Conditional rendering
- Component reusability

---

## 🛠️ Tech Stack

- React
- Tailwind CSS
- Framer Motion
- OMDb API
